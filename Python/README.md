
# Student Information System

## Project Overview
A simple Python application that collects and
displays student information.

## Features
- Collects student name and age
- Receives university and major information
- Accepts GPA as a decimal number
- Displays a formatted student profile

## Concepts Used
- Variables
- Data Types
- User Input
- Output Formatting
- Type Conversion

## Technologies
- Python 3.14
- Visual Studio Code

## How to Run

```bash
python student_information.py
```

## Learning Objectives
This project demonstrates the fundamentals
of Python programming through a simple
student information management application.
